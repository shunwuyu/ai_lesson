- useRef
useRef是React中的一个钩子函数，它允许你持久化地**存储**一个可变的值或访问**DOM节点**，且不会触发组件**重新渲染**。

- 称useRef为“响应式对象”不太准确
  useRef提供对DOM节点或值的引用，但不会因值的变化而触发组件重新渲染，不具备响应式特性。

- demo1

useRef 用来持久存放 web‑worker 实例，组件每次渲染不会重置该线程对象，方便监听消息、发送数据以及组件卸载时销毁线程。

如果是变量就会重置， 用useState, 它又不需要响应变化，useRef 专门用于存储非响应式数据的可变引用。


JavaScript 为主线程单线程机制，主线程负责脚本执行、DOM 渲染和用户交互，为避免多线程操作 DOM 产生冲突。繁重的 CPU 计算会阻塞主线程，造成页面卡顿，于是浏览器提供 Web‑Worker 开辟独立后台线程承担纯计算任务。worker 无法访问 DOM，只能通过消息和主线程通信。它只是浏览器提供的辅助线程，页面渲染、组件更新、交互事件依旧只能在唯一 JS 主线程运行，因此 JS 仍旧属于单线程语言。
