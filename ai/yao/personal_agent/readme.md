# Personal Agent

最近， Meta的Muse, xAI 的Grok Bot, 接连把一个词摆到我面前：
Personal Agent, 个人智能体。 他想做一个长期为你去办事的AI 助手。
我们已经有了能记住偏好的聊天助手了（chatgpt），也有能去使用工具完成任务的Agent
(Codex, WorkBuddy) , 那么 Personal Agent 往前走了哪一步？  

举例子：

拿办活动来说， 你让Ai 去找10家场地，做一张对比表， 这次任务就完成了。
活动还没有办成， 过了3天， 有一家涨价了， 一位嘉宾来不了了， 你还得去继续协调。
你希望找AI的时候， 你希望它知道之前就推进到了哪里， 拿了新的情况， 就能接着去处理。
以后办类似的活动， 它也能用上次积累的经验。

Personal Agent 强调的是围绕你这个人， 持续的去提供帮助， 事情会变，但对你的了解
是可以积累下来的。 这个是一种产品的方向， 和聊天助手、任务型Agent之间，有不少重叠，
具体到今天的产品， 要看他能实际做什么。

我们，先看meta muse , meta 为他准备了独立的云端电脑和浏览器，
他可以去打开网页， 填写表单， 用应用推进业务， 关闭应用后， 耗时的工作任然可以继续
要批准的时候，再回来，再去找到你， 给了AI可以持续工作的地方， 任务交代出去， 
你就不必一直守着聊天窗口， 能一直运行.

Grok bot 允许你创建不同职责的bot , 让他们保持不同的背景， 并且相互交接的工作。
比如， 有销售、运营，有工程的不同分工， 同时去推进几件事情的时候， 每项工作都有
相应的助手去负责， 需要合作的时候， 再把它给完全的联系起来。

个人智能体正在补齐的条件， 它需要一个能够去工作的环境， 也需要与外部服务打交道的方式。
